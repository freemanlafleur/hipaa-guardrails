# Synthetic data conventions

Every value in tests, seeds, fixtures, demos, screenshots, docs and evals is invented. These conventions make fake data recognizable to people and to the checker.

| Field | Use | Why |
|---|---|---|
| Email | `jordan.reyes@example.com`, `pt-0042@clinic.test` | Reserved domains never deliver mail |
| Phone | `(312) 555-0100` to `555-0199` | Reserved for fiction in North America |
| SSN | Start with `9`: `900-12-3456` | Never issued |
| MRN / ids | Prefix `TEST-` or `SYN-`: `SYN-000123` | Obvious in any screen or log |
| Names | From a fixed fake list or a seeded faker, never from real charts | |
| Dates of birth | Generated, and the file is marked synthetic | DOBs can't be told apart from real ones |
| Addresses | `123 Example St, Springfield` | |
| Clinical text | Written for the test, or generated; never pasted from a real note | |

## Marking a file

Put the word `synthetic-data` in any test, seed or fixture file that holds person-shaped fields (names, DOB, address, phone, diagnosis...). For example:

```ts
// synthetic-data: generated by tests/factories/patient.ts, no real patients
```

```json
{ "_meta": "synthetic-data", "patients": [ ... ] }
```

```sql
-- synthetic-data: demo clinic seed
```

The marker is a promise a person makes after checking. Don't add it to a file you haven't confirmed is fake.

## Generating data

Prefer factories with a fixed seed (for example `@faker-js/faker` with `faker.seed(42)`, or Python `Faker.seed(42)`) so tests are repeatable. Faker libraries run locally and send nothing anywhere.

## Never

- Copy production rows into a fixture, even with names changed. Real combinations of DOB, zip code and condition can still identify someone.
- Point a preview, staging or local environment at the production database.
- Use a real patient's chart to "make the demo realistic".
- De-identify real data for development without the policy owner's sign-off. HIPAA's de-identification methods (Safe Harbor's 18 identifiers, or expert determination) are a compliance decision, not a script.
